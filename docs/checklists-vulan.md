# Checklists — Vulan

## Para iniciar projeto

- Proposta aprovada
- Contrato ou aceite registrado
- Entrada paga
- Briefing respondido
- Logo recebido
- Conteúdo mínimo recebido
- Contatos recebidos
- Acessos necessários disponíveis

## Antes da publicação

- Desktop testado
- Mobile testado
- Links funcionando
- WhatsApp correto
- Formulários funcionando
- Textos revisados
- Imagens otimizadas
- Favicon
- Title e meta description
- Open Graph
- HTTPS
- Domínio
- Sitemap
- Robots
- Página 404
- Política de privacidade e termos
- Painel testado, quando existir
- Aprovação final registrada
- Saldo final recebido

## Depois da publicação

- Site publicado
- Acessos entregues
- Treinamento do painel, quando existir
- Orientação básica
- Início dos 7 dias de suporte
